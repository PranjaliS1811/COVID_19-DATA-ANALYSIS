# COVID_19-DATA-ANALYSIS

#About the Project
This project analyzes COVID-19 data using Python to identify trends in confirmed cases, deaths, recoveries, and other key indicators.

# 📊 Key Features

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Analysis of confirmed cases, deaths, and recoveries
- Time-based trend analysis
- Country/region-wise comparison
- Data visualization using charts

  # 🛠️ Tech Stack

- Python
- Pandas – Data manipulation and analysis
- NumPy – Numerical computations
- Matplotlib – Data visualization
- PoweBI- Dashboard
- Seaborn – Statistical visualization
- Google Colab – Development environment
